# بازبینی ظاهری تقویم

Tailwind و DaisyUI در این پکیج نصب نیستند. استایل از `resources/css/calendar.css` می‌آید و متغیرهای DaisyUI را اگر میزبان آن‌ها را تعریف کرده باشد می‌خواند. منوی پایین «وظایف / یادداشت / بیشتر» و تنظیم‌هایی مثل شمارهٔ هفته در پکیج وجود ندارند و ساخته نشدند.

رفتار تاریخ، نماها، جستجو، فیلتر و مجوزها در تست‌های PHPUnit موجود است. این فهرست فقط برای چشم است.

| شماره | چه را ببینید | کجا پوشش داده شده |
| --- | --- | --- |
| 01 | ماه شمسی و نام روزها | `tests/Scenarios` و تقویم `locale=fa` |
| 02 | تعویض شمسی و میلادی | سوییچ system در نوار ابزار |
| 03 | ماه قبل و بعد | دکمه‌های previous / next |
| 04 | امروز | دکمهٔ امروز و کلاس `is-today` |
| 05 | انتخاب روز | `openDay` و کشوی رویدادهای همان روز |
| 06 | چند رویداد در یک سلول | `+N` و نقطهٔ رنگی در عرض زیر ۷۲۰ |
| 07 | نوار چندروزه | `month-span` در دسکتاپ |
| 08 | عبور از دو ماه | همان نوار، بدون تغییر محاسبه |
| 09 | جستجو | فیلد جستجو، محدودیت scope سمت سرور |
| 10 | خاموش کردن یک منبع | تراشه‌های سایدبار |
| 11 | روشن و تاریک | `theme=light` و `theme=dark` |
| 12 | موبایل | هفت ستون، بدون اسکرول افقی ماه، نقطه به‌جای متن سلول |
| 13 | ماه، هفته، روز، فهرست | سوییچ نما |
| 14 | عنوان فارسی و انگلیسی | `dir="auto"` روی عنوان رویداد |
| 15 | صفحه‌کلید | `focus-visible` روی دکمه، ورودی و رویداد |
| 16 | رویداد زیاد | دکمهٔ بیشتر، ارتفاع ردیف ثابت |
| 17 | کبیسه و مرز سال | تست‌های تاریخ موجود، نه محاسبهٔ جدید |
| 18 | مجوز | تست‌های Security و Integration |
| 19 | خطای منبع | نوار `source_failed` |
| 20 | رگرسیون | `composer test` |

دستور تصویر واقعی، بعد از `php vendor/bin/testbench serve --port=8765`:

```bash
npm run shots -- fa light desktop personal
npm run shots -- fa dark desktop personal
npm run shots -- fa light mobile personal
npm run shots -- fa dark mobile personal
```
