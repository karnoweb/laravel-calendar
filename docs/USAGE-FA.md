# راهنمای استفاده

## ورودی‌های کامپوننت

```blade
<livewire:calendar::calendar calendar-key="personal" ... />
```

| ورودی | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `calendar-key` | string | الزامی | کلید تقویم تعریف‌شده در Factory |
| `layout` | `full` \| `compact` | `full` | `compact` برای ویجت‌های کوچک: بدون سایدبار، بدون جست‌وجو، سلول‌های فشرده |
| `views` | آرایه | همه | زیرمجموعه‌ی `month`, `week`, `day`, `list` |
| `default-view` | string | اولین view فعال | view اولیه (باید در `views` باشد) |
| `systems` | آرایه | هر دو | `gregorian` و/یا `jalali`. اگر فقط یکی باشد دکمه‌ی تغییر نمایش داده نمی‌شود |
| `system` | string | تنظیم تقویم | سیستم تقویمی اولیه |
| `sources` | آرایه | همه | محدود کردن منابع، مثلاً `['tasks','holidays']` |
| `preset-filters` | آرایه | `[]` | فیلتر ثابت و غیرقابل تغییر برای کاربر، مثلاً `['status' => 'open']` |
| `locale` | `en` \| `fa` | زبان برنامه | زبان و جهت نمایش |
| `url-sync` | bool | `true` | همگام‌سازی وضعیت با URL. در داشبورد یا وقتی چند تقویم در یک صفحه است `false` بگذارید |
| `url-prefix` | string | `''` | پیشوند پارامترهای URL برای چند تقویم |

همه‌ی این ورودی‌ها فقط **محدود** می‌کنند، نه گسترش: نمی‌شود چیزی را فعال کرد که تعریف تقویم اجازه نداده. مقدار نامعتبر (مثل view ناشناخته) خطای 404 می‌دهد، و کاربر نمی‌تواند این مقادیر را از مرورگر تغییر دهد.

اگر `sources` هیچ منبع معتبری باقی نگذارد، دسترسی رد می‌شود.

## ارتفاع و عرض

کامپوننت همیشه `100%` عرض و ارتفاع کانتینر خود را می‌گیرد؛ هیچ‌وقت صفحه را بلند نمی‌کند. اسکرول فقط داخل خود تقویم است (شبکه‌ی هفته/روز و لیست).

- ارتفاع را **میزبان** تعیین می‌کند: `height: 360px`، یک flex-child، یا `calc(100dvh - ...)`.
- اگر کانتینر ارتفاع نداشته باشد، تقویم به اندازه‌ی محتوا رشد می‌کند.
- در نمای ماه، رویدادهایی که در سلول جا نمی‌شوند پنهان می‌شوند و دکمه‌ی `+N` روز را باز می‌کند.
- در نمای هفته/روز، اسکرول به‌صورت خودکار روی «اکنون» (یا ساعت ۷) می‌رود.
- واکنش‌گرایی بر اساس **عرض کانتینر** است (`<480px` فشرده، `<900px` متوسط)، نه عرض پنجره؛ پس یک ویجت باریک در صفحه‌ی بزرگ هم درست دیده می‌شود.

صفحه‌ی کامل:

```blade
<div style="height: 100dvh; display:flex; flex-direction:column">
    <header>...</header>
    <div style="flex:1; min-height:0"><livewire:calendar::calendar calendar-key="personal" /></div>
</div>
```

`min-height: 0` روی والد flex ضروری است.

## تقویم گوگل

```php
->sources([...])->google(true)   // false = غیرفعال
```

نیازمند یک `GoogleAccessTokenResolver` در پروژه است (پکیج OAuth اجرا نمی‌کند). بدون توکن، منبع خالی است، نه خطا. نوشتن در گوگل پیش‌فرض خاموش است: `CALENDAR_GOOGLE_WRITABLE=true`. جزئیات در README.

## تعطیلات رسمی

```php
->sources([...])->holidays(true)   // false = غیرفعال
```

منبع فقط‌خواندنی و بدون شبکه است؛ داده از `config('calendar.holidays')` می‌آید:

- `jalali`: تعطیلات ثابت شمسی `[ماه, روز, 'English', 'فارسی']` (پیش‌فرض: نوروز، ۱۲ و ۱۳ فروردین، ۱۴ و ۱۵ خرداد، ۲۲ بهمن، ۲۹ اسفند).
- `gregorian`: تعطیلات ثابت میلادی با همان قالب.
- `dates`: تاریخ‌های مشخص: `['date' => '2026-03-20', 'title' => '...', 'title_fa' => '...']`.

**محدودیت:** تعطیلات قمری (تاسوعا، عاشورا، اعیاد و ...) هر سال جابه‌جا می‌شوند و داخل پکیج نیستند؛ باید هر سال در `dates` وارد شوند. این اتفاق خودکار نمی‌افتد.

## فعال/غیرفعال کردن نماها

```blade
:views="['month', 'list']"
```

- فقط یک view → انتخاب‌گر نما نمایش داده نمی‌شود.
- تلاش برای رفتن به view غیرفعال (از طریق URL یا درخواست دستی) نادیده گرفته می‌شود و به view پیش‌فرض برمی‌گردد.
- می‌توانید در Factory هم محدود کنید: `new CalendarSettings(enabledViews: [CalendarView::Month], ...)`.

## جلالی و میلادی

- هر دو سیستم به‌صورت پیش‌فرض فعال‌اند و کاربر با دکمه‌ی بالا جابه‌جا می‌کند.
- فقط یکی: `:systems="['jalali']"`.
- شروع هفته و روزهای تعطیل هر سیستم در `config/calendar.php` (`first_weekday_jalali`، `weekend_days_jalali` و معادل میلادی).
- تاریخ‌ها داخلی همیشه میلادی ISO ذخیره می‌شوند؛ سیستم فقط نمایش و ناوبری را تعیین می‌کند.

## زبان (locale)

- `locale="fa"` یا `"en"` روی هر نمونه. روی `app()->setLocale` همان درخواست هم اثر می‌گذارد.
- بدون آن، زبان برنامه استفاده می‌شود.
- جهت (RTL/LTR) از زبان تعیین می‌شود مگر در تنظیمات استایل مقدار صریح داده شود.
- ارقام در `fa` فارسی نمایش داده می‌شوند.

## فیلتر از پیش تعریف‌شده

`:preset-filters="['status' => 'open']"` روی هر درخواست اعمال می‌شود و فیلتر کاربر با همان کلید را بازنویسی می‌کند. فقط فیلترهایی که در تعریف تقویم وجود دارند اثر دارند.

## چند تقویم در یک صفحه

برای هرکدام `:url-sync="false"` بگذارید، یا `url-prefix` جدا بدهید تا پارامترهای URL با هم تداخل نکنند.

## اگر اشتباه کردم

- نوشتن اشتباه در `views`/`layout`/`locale`: خطای 404، چیزی نادیده گرفته نمی‌شود.
- تعطیلات اشتباه: در `config('calendar.holidays')` اصلاح کنید؛ رویدادی ذخیره نمی‌شود.
